# Terminology

When communicating with users, always use these terms. The English column is the term for `(en)` mode; the Japanese column is the term for `(ja)` mode.

| Term (en) | Term (ja) | Old / API term | Description |
|---|---|---|---|
| **Workspace** | **ワークスペース** | Enterprise | The top-level organizational unit. Members and shared teams belong here. |
| **Project** | **プロジェクト** | Organization, Group | A unit within a workspace. Apps, teams, and distribution pages belong here. A default project is created with the workspace. |
| **Team** | **チーム** | — | A group within a project with a role (owner/developer/tester). |
| **Shared Team** | **共有チーム** | — | A workspace-level team that can be assigned to apps across multiple projects. |

**Important (en):** Never say "organization" or "group" to users — always say "project". When a user belongs to multiple projects, ask "Which project should we upload to?" (not "workspace").

**Important (ja):** ユーザに「organization」や「group」と言わない — 必ず「プロジェクト」と言う。ユーザが複数のプロジェクトに所属している場合は「どのプロジェクトにアップロードしますか？」と聞く（「ワークスペース」ではなく）。
