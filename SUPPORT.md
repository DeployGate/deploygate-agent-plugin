# Support

## Project status

This repository is an open-source DeployGate plugin maintained on a
best-effort basis. The code is provided **as-is**, without warranty of
any kind. Maintainers may not respond to every issue or pull request,
and there is no service-level agreement for triage or fixes.

If you depend on this plugin for production work, please pin a version
you have validated and be prepared to maintain a fork.

## Where to get help

| You want to...                                              | Go to                                            |
|-------------------------------------------------------------|--------------------------------------------------|
| Ask about the DeployGate service (accounts, billing, web app behavior, API access) | https://intercom.help/deploygate |
| Look up how the DeployGate service works                    | https://docs.deploygate.com                      |
| Report a bug in *this plugin*                               | GitHub Issues → Bug report                       |
| Suggest a feature for *this plugin*                         | GitHub Issues → Feature request                  |
| Report a documentation problem in *this repository*         | GitHub Issues → Docs issue                       |
| Report a security vulnerability                             | help@deploygate.com (do not open a public issue) |

When opening an issue on this repository, please use one of the issue
templates. Issues that are actually service-support questions will be
redirected to the DeployGate support channel and closed.
